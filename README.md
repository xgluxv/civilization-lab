# 文明实验室 Ⅱ · 执政者

一款完全离线的中文文明策略沙盒。你执政一个文明，安排建设、选择研究、处理议事，探索遗迹并经营外交；其他五个文明会自主竞争。游戏保持可复现的历史、单文件运行和旧存档兼容。

## 立即游玩

双击 `index.html`，用现代浏览器打开。无需安装、联网、账号或API密钥。现有本地预览也可刷新使用新版。

推荐第一局：选“丰饶大陆”、晨曦联邦和“繁荣之路”。处理开局议事，研究轮作农法或精良工具，安排粮仓或伐木场，然后推进时间。顾问会根据当前状态提供提示。

`classic.html` 保留第一版。新版的界面和运行代码约184 KB，所有资源都已内嵌。若浏览器限制本地文件的后台工作线程，请使用本地静态服务器打开；存档重建使用工作线程以保持界面响应。

## 新增玩法

### 城市建设与开拓

10种建筑：粮仓、农庄、伐木场、工坊、图书馆、集市、城墙、医馆、学院和全球唯一的穹顶观星台。建筑先扣资源，再按年施工。每城最多排3项工程，部分建筑可升级。取消工程返还未施工部分80%的投入，后续同类升级一并取消。

普通建筑的文明加成取各城平均，城墙只防御所在城市；研究与奇观加成全局生效。你需要手动建立新城市：在地图点击本国土地或相邻无主陆地，界面会显示条件与成本。需要160人口、80粮食、90木材、120财富，与所有现有城市相隔至少约4格。山地不能建城，每个文明最多主动建立12座城市。已有土地仍会自动扩张。

### 四条研究路线

12项专项研究分为民生、工程、学术、商贸，每条3项。前置研究与时代等级决定解锁条件。花费研究点后立即生效，所有路线均可学习，顺序决定发展优势。原有12个时代阶段继续自动推进。

### 议事与取舍

4类议事、12种选择，包含资源交换、人口增长、短期建设加速、学术资助和节庆。每次选择的收益与成本都写在按钮上。玩家议事在页面中会暂停时间，防止快进跳过选择；引擎离线回放可以按记录处理，长期无人干预则由议会自动决定。

### 遗迹远征

程序生成最多20处遗迹，包含失落书库、古老圣林、沉眠宝库和远古高塔。每次远征花费30粮食、25财富，每文明同时只能派1支队伍。距离决定耗时，专项研究扩展范围、缩短行程。遗迹有8%至18%的失败率；失败后需等待8年，成功后获得一次性奖励。地图显示远征路线与当前位置。

### 外交与冲突

可以派遣使节、宣战和谈判停战。使节消耗35财富，每对文明、每方12年冷却；关系超过38可签署通商条约。宣战消耗40财富，必须接壤并遵守停战协议。停战谈判消耗100财富，提供30年保护。战争会占领领土和城市，城市的建筑与未完工项目随城市转移。

### 三条胜利路线

| 路线 | 同时满足的条件 |
| --- | --- |
| 繁荣之路 | 1,200人口、4座城市、12级建筑、85%幸福度 |
| 知识之光 | 9项专项研究、时代科技6级、成功发掘3处遗迹、拥有穹顶观星台 |
| 四海同盟 | 4份通商条约、3,000财富、10级建筑、连续和平40年 |

目标只能在开局、尚未实施建设等关键操作前更改。胜利会记录年份，不强制结束模拟。沙盒资源援助、天气、全局环境参数或控制其他文明的政策，会标记“辅助通关”。建设、研究、外交与本国政策属于正常玩法。

## 存档、升级与恢复

- “保存”使用新版独立槽位，经典版存档不被覆盖。
- “读取”优先读取新版槽位，没有时尝试旧版槽位。
- 旧版JSON先用内嵌的经典引擎精确还原资源、城市与领土，再从存档年份进入新版。
- 新版存档可以从其起点精确回放。旧版升级存档的回放起点是升级年份；更早的历史可以在 `classic.html` 中读取原版存档。
- “生成”“读取”“导入”“回到历史”成功替换世界前，会保留一份恢复记录。“恢复”可以找回该记录，也可以在前后两份世界间切换。
- 本地存储可能被浏览器清理或按文件路径隔离；重要进度请导出JSON。存档重建在后台工作线程运行，可取消。

同版本、同种子、同场景与同顺序的操作能得到完全相同的状态。世界上限为50,000年、10,000次记录操作、2 MB导入文件。曲线保留最近601个数据点，编年史保留260个事件，界面显示最近40条匹配事件。

## 地图与键盘

圆点代表城市，双环圆点代表原始首都，菱形代表遗迹。点击城市管理建设，点击遗迹查看远征，点击土地查看开拓条件。地图按钮可缩放至4倍；放大后可用鼠标拖动。手机可用遗迹列表的定位按钮。

地图获得键盘焦点后，方向键移动、回车或空格选择。执政大厅标签支持左右方向键、Home和End。切换文明观察不会改变玩家身份；“返回我的文明”快速返回。页面进入后台时暂停演化。

## 开发和验证

游戏本身与引擎测试无第三方运行依赖。Node.js 18及以上可构建，界面事件测试使用开发依赖 jsdom。

```powershell
npm ci
npm run build
npm test
npm run test:ui
npm run test:playthrough
```

- `src/content.js`：建筑、研究、议事、遗迹和目标定义。
- `src/engine.js`：确定性规则、AI、合法性检查、存档与回放。
- `src/legacy-engine.js`：冻结的第一版引擎，仅用于旧存档升级。
- `src/app.js`、`shell.html`、`style.css`：交互、绘制和响应式界面。
- `build.cjs`：打包所有源码为 `index.html`。

2026-09-24新版验证：25组引擎测试；jsdom中验证了开局选择、议事、研究、建设、远征、事件自动暂停、外交、目标、存读档、恢复、回放、地图按钮、键盘、自动播放及非默认文明。后台工作线程的实际打包代码在测试中执行。三条目标各完成一次无辅助自动游玩并验证最终状态精确回放。

**验证边界：** 本轮浏览器连接不可用，未完成新版的真实浏览器渲染、手机布局或Canvas像素检查。jsdom测试模拟了Canvas绘图接口与工作线程容器，因此不能替代视觉检查、浏览器权限测试或真实性能测量。第一版的浏览器检查不能视为新版的验证结果。

## 模型边界

文明、历史与参数都是虚构。人口、财政、科技、战争和疫病采取简化规则，不用于真实历史或社会预测。运行游戏只使用本机计算，不调用AI服务，也不继续消耗模型token。
